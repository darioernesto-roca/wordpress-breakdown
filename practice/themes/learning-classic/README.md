# Learning Classic practice theme

This minimal installable classic theme demonstrates the required theme header,
setup hooks, asset enqueueing, menu registration, the Loop, template hierarchy,
escaping, translation-ready strings, `wp_body_open()`, `wp_head()`, and
`wp_footer()`.

It is intentionally not a production design. Exercises:

1. Add `archive.php`, `page.php`, `404.php`, and a reusable template part.
2. Add `theme.json` design tokens and editor styles.
3. Render featured images with meaningful alt-text behavior.
4. Add accessible comments and a widget area.
5. Test the Theme Unit Test data at 200% and 400% zoom.
