# Notes

This directory is the informal lab notebook. Use it for observations about tools,
experiments, debugging sessions, conference/course notes, and questions worth
revisiting. Durable tutorials belong under `docs/`; runnable code belongs under
`practice/` or `examples/`.

Start with [`NOTE-TEMPLATE.md`](NOTE-TEMPLATE.md). Never paste production secrets,
personal information, customer data, private URLs, licenses, or raw database
exports into a note.
